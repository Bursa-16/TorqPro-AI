# TorqPro AI v3.3.2

## Release Scope

This release completes the Tool Tracking modernization delivered under:

**VISUAL-02C-C2 — Tool Tracking Frontend/API**

## Highlights

- Native React Tool Tracking workspace
- Persistent Tool Tracking backend and SQLite migration
- Tool repository, schemas, service layer, and API routes
- Read and write Tool Tracking API
- Role-aware permissions for viewer, engineer, and admin
- Tool create and update workflows
- Soft deactivation with preserved capability history
- Immutable capability-study history
- Latest capability-study projection
- Effective status handling
- Tool Tracking summary endpoint
- Audit integration for Tool Tracking mutations
- Frontend live API integration
- Tool create, edit, capability-study, and deactivate UI flows
- Null-safe Cm/Cmk and last-capability rendering
- Responsive Tool Tracking workspace and mobile sidebar behavior

## API

Tool Tracking exposes:

- `GET /api/tools`
- `POST /api/tools`
- `GET /api/tools/summary`
- `GET /api/tools/{tool_id}`
- `PATCH /api/tools/{tool_id}`
- `DELETE /api/tools/{tool_id}`
- `GET /api/tools/{tool_id}/capability-studies`
- `POST /api/tools/{tool_id}/capability-studies`
- `GET /api/tools/{tool_id}/capability-studies/latest`
