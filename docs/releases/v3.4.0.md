## Advanced Analysis — VDI 2230 Expansion

This release substantially expands the Advanced Joint Analysis module beyond the
base load-distribution factor (Φ) calculation.

### Axial Operating Stress Assessment (VDI-ENG-04A)

- Computes σ_axial from assembly preload F_M and additional bolt force ΔF_b
- Utilises tensile stress area A_s (mm²) and proof stress Rp0.2 (MPa)
- Reports utilisation ratio η_axial = σ_axial / Rp0.2
- Status: BELOW_RP02 / AT_RP02_BOUNDARY / ABOVE_RP02

**Scope disclaimer:** This assessment covers axial bolt stress only. Tightening
torsion is not included. This is not the full VDI 2230 reduced stress check
(σ_red = √(σ_z² + 3τ²)). Backend extension would be required for the complete
yield safety assessment.

### Separation Safety / Residual Clamp Force (VDI-ENG-04B)

- Computes residual clamp force F_K,res
- Clamp force loss ΔF_k
- Separation load limit F_A,sep
- Status: CLAMPED / SEPARATION_BOUNDARY / SEPARATED

### Joint Stiffness (VDI-ENG-04C)

- Bolt stiffness c_b (kN/mm) from compliance δ_b
- Clamped-part stiffness c_p (kN/mm) from compliance δ_p
- Force–displacement diagram when F_M > 0

### Average Bearing / Contact Pressure (VDI-ENG-04D)

- Contact annulus area A_contact from D_outer and clearance hole d_h
- Average bearing pressure p_avg = F_M / A_contact (MPa)

**Scope disclaimer:** p_avg is the scalar average contact pressure over the
annular bearing area. This is not a radial pressure distribution and is not
FEA-derived. The schematic contact visual is qualitative only.

## Parameter-Context Engineering Diagrams

Focus on any input field now updates the Engineering Context panel with a
field-specific schematic and live value:

| Field | Symbol | Unit | Diagram type |
|-------|--------|------|--------------|
| Plate thickness | t | mm | Cross-section with dimension arrow |
| Bolt length | L | mm | Axial bolt with dimension arrow |
| Load introduction factor | n | — | Two-plate load-entry arrows |
| Operating load | FA | kN | Axial tension arrows |
| Assembly preload | F_M | kN | Compression arrows |
| Temperature difference | ΔT | °C | Thermal expansion arrows |
| Tensile stress area | A_s | mm² | Shaded area cross-section (not a diameter) |
| Proof stress | Rp0.2 | MPa | Material property block |
| Plate material | — | — | Material stiffness block with E value |
| Outer contact diameter | D_outer | mm | Plan-view annulus with dimension |
| Clearance hole diameter | d_h | mm | Cross-section hole with dimension |

Live focus and value updates occur on `onFocus`, `onClick`, Tab, and value
change — no Calculate trigger required.

**Semantic guards preserved:**
- A_s is rendered as a shaded area, never as a diameter.
- Rp0.2 is a material property block, not a geometric dimension.
- D_outer is labelled D_outer throughout, not Dw.
- n is not rendered as Φ.
- F_M is not rendered as F_K,res.
